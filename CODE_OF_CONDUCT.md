# Code of conduct

This project follows the spirit of the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

**We want** a welcoming, harassment-free place for everyone, whatever their background, identity,
experience or opinions. Be kind, assume good intent, give and take feedback gracefully, and focus on
what is best for the people who will use this kit.

**Not acceptable:** harassment, insults or personal attacks, sexualised language or imagery, trolling,
publishing others' private information, and any conduct you would not accept in a professional
setting.

**Scope:** this repository, its issues, pull requests and discussions, and project spaces online.

**Reporting:** contact the maintainer privately through GitHub (@sametkilictas). Reports are handled
confidentially and fairly. The maintainer may edit or remove contributions, or restrict participation,
when this code is not respected.
