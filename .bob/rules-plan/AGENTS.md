# 🗺️ Plan override — routing protocol

In this repository the built-in Plan mode is read-only. Plans that will be committed are written by
**📐 Spec Architect** with `/sdd-plan F##`, because they need the plan template, the Constitution
check, contract updates and a hash-bound human approval.

- Read-only architecture questions: answer from `sdd/specs/02-architecture.md`, `sdd/specs/03-domain-model.md`,
  `sdd/specs/04-api-guidelines.md` and `sdd/adr/`.
- Any request to create or change a plan, spec, contract or ADR: explain in one sentence and offer to
  switch to 📐 Spec Architect (use the mode tool when they agree).
- Start replies with the orientation line from rule 06 §2.
