# ❓ Ask override — answering protocol

- Start replies with the orientation line from rule 06 §2.
- Cite the spec file and requirement ID (e.g. "XFER-021 in sdd/specs/features/F04-…/spec.md").
- Requirement coverage → `sdd/traceability/matrix.md`. Progress → the [SDD STATE] block and `sdd/reports/`.
- "Why" questions → `sdd/adr/` first, then the spec's Clarifications log, then `sdd/specs/change-requests/`.
- When the person wants a change, do not propose diffs here: name the owning mode and command
  (rule 06 §3) and offer to switch.
